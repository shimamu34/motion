# motion実機確認キット

このキットは、`motion`の**修正中のアプリ**を実機で試すためのものです。学校の本番アプリではありません。

## 内容
- `index.html`：修正ブランチのアプリ本体（GitHubから自動取得）
- `sample-motion.mp4`：人が映らない動く模様の約8秒動画
- `sample-second.mp4`：動画切替用、人物のいない約6秒動画
- `VERSION.txt`：GitHubブランチとコミット
- `CHECKLIST.txt`：結果記録欄

**大切：ネットワークへの通信**：アプリの骨格推定にはTensorFlow.jsなどの外部CDNへの接続が必要です。動画ファイルそのものを外部へアップロードする機能は実装されていませんが、使用前に学校のルールを確認してください。

## Chromebook・PCでの確認（おすすめ）
1. このZIPをダウンロードして解凍し、`index.html`をChromeで開きます（ドラッグ＆ドロップも可）。
2. 最初の「ファイルを選択」から`sample-motion.mp4`を読み込んでください。
3. 再生・停止、速度変更、スライダーでの移動、左右反転、1コマ送りを試してください。
4. 別の`sample-second.mp4`へ切り替えます。
5. 画面に表示される日本語メッセージを確認します。「姿勢モデルを読み込めません」と出ても、**動画自体が見え再生できれば**今回の改善目標に合っています。
6. 骨格表示については、このテスト動画には人物がいないため骨格点が出なくても正常です。実際の骨格検出はTensorFlow公式の公開テスト動画など、学校の規定に合う素材で別途確認してください。

## iPhone Safariについて
iPhoneの「ファイル」アプリのHTMLプレビューではJavaScriptを実行できない場合があります。その場合は「アプリの不合格」ではなく**テスト未実施**として記録してください。ローカルHTMLをSafariで開けない場合、別途テスト用サイトなどの方法を検討します（公開・デプロイには追加の承認が必要です）。

## 判定時の注意
- 動画を外部AIにアップロードしないでください。
- 人が映る学校の授業動画・生徒の個人情報は使わないでください。
- Chromebookの端末・OS・Chromeのバージョンがわかれば記録する程度で十分です。
- 30fps以外の「厳密な1コマ送り」、動作中の骨格位置の完全同期は**まだ改善前の別課題**です。
- テストをしないまま実機の合格を報告しないでください。
