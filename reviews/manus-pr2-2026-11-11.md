### High: `render()`がメディア準備前に終了し、骨格描画ループが再開しない可能性

- **ファイル:** `index.html`
- **行:** 277–293、特に282行
- **問題:**

```js
if (this.video.readyState < 2 || !this.video.videoWidth || !this.video.videoHeight) return;
```

`onplay`は動画の再生開始時点で発火しますが、その時点で`readyState < 2`の可能性があります。この場合`render()`は何もスケジュールせずに終了します。

その後、`loadedmetadata`ではメタデータ更新だけを行い、`render()`を再開していません。そのため、以下の状態になり得ます。

- 通常のMoveNetモードで黒いCanvasや骨格が更新されない
- 骨格表示が最初のフレームから開始されない
- モデル読込完了後も動画再生中の描画ループが存在しない

既存コードにはなかった準備状態チェックを追加したことで、通常時のMoveNet表示を壊す回帰になり得ます。今回のオフラインテストは`readyState = 4`を固定しているため、このタイミング問題を検出できていません。

- **修正案:**

`loadeddata` / `canplay`で再描画を開始する、または準備未完了時にも次の`requestAnimationFrame`を予約して再試行してください。例えば概念的には次のようにします。

```js
if (this.video.readyState < 2 ||
    !this.video.videoWidth ||
    !this.video.videoHeight) {
  if (!this.video.paused && !this.video.ended) {
    this.animationId = requestAnimationFrame(() => this.render());
  }
  return;
}
```

ただし、`render()`の多重起動を防ぐ状態管理も併せて必要です。

### Medium: モデル読込完了時に描画ループが二重起動する可能性

- **ファイル:** `index.html`
- **行:** 290–292、401
- **問題:**

動画再生中にモデルの読込が完了すると、既存の`render()`が`await this.estimatePoses()`で待機している可能性があります。その直後に401行の処理が実行されます。

```js
if (!player.video.paused) player.render();
```

この結果、既存の描画ループに加えて新しい`render()`ループが開始され、`requestAnimationFrame`のチェーンが二重化する可能性があります。

影響として、以下が考えられます。

- MoveNet推論が重複して実行される
- CPU/GPU使用率が上がる
- フレーム描画が競合する
- 一時停止後も、古いループ由来の処理が残る可能性がある

PR本文でも非同期推論ループ競合は別フェーズ扱いとされていますが、このPR自身がモデル読込完了時に明示的に`render()`を追加しているため、今回の変更によって発生し得る問題です。

- **修正案:**

`render()`の起動を1箇所に統一し、`isRendering`などのフラグで多重起動を防いでください。あるいは、モデル準備完了時に既存ループを無効化する世代番号を更新してから、1本だけ再起動してください。

### Medium: `play()`の同期例外を処理していない

- **ファイル:** `index.html`
- **行:** 228–235
- **問題:**

```js
const playPromise = this.video.play();
```

Promiseがrejectされる通常ケースは`catch()`で処理されていますが、`play()`呼出し自体が同期的に例外を投げる環境・モック・異常状態では、その例外がイベントハンドラまで伝播します。ステータスも再生失敗表示に更新されません。

今回のテストは`play()`が常に`Promise.resolve()`を返すだけで、rejectケースおよび同期throwケースを検証していません。

- **修正案:**

呼出し自体を`try/catch`で囲み、Promise rejectと同じエラーステータスに統一してください。

```js
playVideo() {
  try {
    const playPromise = this.video.play();
    if (playPromise && typeof playPromise.catch === 'function') {
      playPromise.catch(() => {
        this.setStatus('動画を再生できませんでした。再生ボタンをもう一度押してください。');
      });
    }
  } catch (error) {
    this.setStatus('動画を再生できませんでした。再生ボタンをもう一度押してください。');
  }
}
```
